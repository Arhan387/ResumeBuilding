Personal Resume Website

A personal resume website created using HTML and CSS as part of the IIM Bangalore BBA DBE Web Development course.

Features
- About, Education, Experience and Contact sections
- Responsive layout using Flexbox and Grid
- Navigation bar and hover effects
- Custom fonts, colours and styling

Technologies Used
- HTML5
- CSS3
- GitHub Pages (Hosting)
