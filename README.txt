ARHAN SIDDIQUI — PERSONAL RESUME WEBSITE

Files:
- index.html: website content and page structure
- styles.css: visual design and responsive CSS

HOW TO PREVIEW:
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.
4. Keep index.html and styles.css in the same folder.

HOW TO HOST:
Upload index.html and styles.css to the root of a public GitHub repository,
then enable GitHub Pages from Settings > Pages > Deploy from a branch >
main > /(root) > Save.

Before submission:
- Check that all personal details are correct.
- Add dates or more detailed descriptions to roles only if you can verify them.
- Test the navigation links and email link.
